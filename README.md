# pairwise-tlas-dynamic

动态场景的 BVH 在角色传送后整棵树重建，帧末才提交，导致同一帧的光线打到旧位置；实例增删只更新叶子没更新父节点包围盒，遍历时漏掉整簇；refit 与 rebuild 阈值按三角形数而不是重叠度，密集植被下树深度爆掉；异步构建在 GPU 上跑，CPU 端却直接读结果，没有等 fence；蒙皮网格每帧重建 BLAS，顶点缓存被下一帧覆写；TLAS 实例掩码在材质切换后没刷新，阴影光线穿墙；遍历栈深度按固定 32 开，深层场景溢出后回绕到根；内存池按最大节点数一次性分配，裁剪后空洞不回收；两帧延迟的 BVH 与当前相机不同步，移动物体边缘出现光漏；多相机各自建树，重复实例把显存打满。render/dynamic_bvh.py 是核心，tests/test_dynamic_bvh.py 15个红。要修的是：传送时同步重建并提交；更新叶子连带祖先；refit 阈值看重叠度；异步结果加 fence；蒙皮 BLAS 双缓冲；实例掩码随材质刷新；遍历栈动态扩容；节点池回收空洞；BVH 与相机帧对齐；多相机共享实例树。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
